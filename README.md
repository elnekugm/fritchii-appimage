# Fritchii v5.5 — Linux AppImage build

Workflow that compiles [Fritchii](https://github.com/Frizti/Fritchii) tag `fritchii-v5.5`
for Linux x86_64 and packages it as an AppImage, replicating the Linux job of the
upstream `release-binaries` workflow.

Run it from the **Actions** tab (workflow `build-fritchii-appimage` → *Run workflow*),
then download the `Fritchii-v5.5-Linux-x86_64` artifact.
